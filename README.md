# bocc-backend — moved to the BOCC monorepo

> ⚠️ **This repository is no longer maintained.**
> The Buffalo Open Coffee Club backend has moved into the unified monorepo.

## ➡️ New home

**https://github.com/z1g1/bocc**

The backend now lives in the [`backend/`](https://github.com/z1g1/bocc/tree/main/backend) directory of that repository. All future development, issues, and deployments happen there.

## What changed

The website and backend were consolidated into a single repository and a single Netlify project. The API is now served same-origin with the website:

- **Website:** https://716coffee.club
- **API:** https://716coffee.club/.netlify/functions/

This repo is kept only for historical reference and will be archived. Do not open issues or pull requests here.
